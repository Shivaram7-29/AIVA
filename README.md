# Placement-Ai 🚀

A comprehensive AI-powered platform for campus placement preparation, featuring an AI Resume Analyzer, Aptitude Test Generator, and an Interactive AI Interviewer.

## ✨ Features
- **AI Resume Analysis**: Get professional feedback on your resume tailored for fresher roles.
- **Aptitude Tests**: Practice with TCS NQT-style questions generated by AI.
- **AI Interviewer**: Experience a realistic mock interview with a hyper-realistic AI avatar.

## 🛠️ Quick Start (Windows)

The easiest way to run this project is to use the provided batch script:

1.  **Ensure you have [Node.js](https://nodejs.org/) and [Python](https://www.python.org/) installed.**
2.  **Double-click `RUN_PROJECT.bat`** in the root folder.
3.  The script will automatically:
    - Install frontend dependencies (`npm install`).
    - Create a Python virtual environment and install backend dependencies.
    - Start the FastAPI backend server.
    - Start the Vite frontend development server.
4.  Once both servers are running, open your browser to **http://localhost:5173**.

## ⚙️ Manual Setup

If you prefer to run things manually:

### 1. Backend Setup
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
*Make sure to check `backend/.env` and add your **GROQ_API_KEY** if it's missing.*

### 2. Frontend Setup
```bash
# In the root directory
npm install
npm run dev
```

## 🔑 Environment Variables
- **Backend**: Create a `.env` file in the `backend/` directory with:
  ```env
  GROQ_API_KEY=your_key_here
  ```
- **Frontend**: The app is configured to connect to `http://localhost:8000` by default.

## 📁 Project Structure
- `/src`: Frontend React components and logic.
- `/backend`: FastAPI Python server and AI logic.
- `/public`: Static assets (images, videos).
